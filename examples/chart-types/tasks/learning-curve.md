# Task: learning-curve

Draw a line chart from `learning-curve.json`, for an ICLR paper.

Data: `epochs`, and `accuracy[method]` for the methods Ours, Mixup and Baseline: 5 runs (seeds) each, one validation accuracy on CIFAR-100 (0–1) per epoch.

Deliverable: the figure in the figures folder with its caption, as `learning-curve.png` and `learning-curve.pdf`.
